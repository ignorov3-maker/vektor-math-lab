# Доработка анимаций и пиксельных аксессуаров

В «Думает» синхронно двигаются корпус, взгляд и лапка у щеки, появляются три пикселя мысли. Состояние читается у чёрной версии без спутника. В «Гордится» персонаж выпрямляется, поднимает кулачок и слегка кивает; на пике появляются две золотые пиксельные искры. Большое конфетти остаётся отдельным состоянием celebrate. Автоматическая смена состояний в демо замедлена до 4,5 секунды, чтобы жесты успевали проиграться.

Панама, шапочка выпускника и листик построены ступенями без гладких диагоналей. Фуражка получила контур. После обратной связи владельца последняя версия выпускной шапочки и фуражки сохранена. Кепка не изменена.

Сачок переработан в открытый пиксельный обод с прозрачной серединой, тонкой сеткой и простой ручкой. Сплошной фон удалён. Квадратный сачок сохраняет квадратную форму, остальные получили вытянутую ступенчатую форму. Головные уборы не перекрывают сачок поверх сетки. Каталог и надетый аксессуар используют один SVG; совпадение проверяется для всех десяти сачков.

Контрольные листы показывают три фазы двух анимаций на трёх цветах и сочетания уборов с сачком. При reduced motion движения отключены, но поза, взгляд и пиксельные знаки состояния сохранены.

Проверены движения, фактическая видимость лапки поверх щеки, пиксельная геометрия уборов, контур фуражки и совпадение предпросмотра с надетым предметом. Новые состояния и методы в публичный контракт не добавлялись.
