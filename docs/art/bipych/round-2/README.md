# Дополнительные варианты Бипыча

Второй набор палитр и пропорций по запросу владельца, 27 октября 2026 года. Все шесть листов — концепты одного семейства персонажей; окончательная версия не выбрана.

- `bipych-lavender-lime.png` — лавандовый с лаймовыми акцентами, вытянутый корпус, неровный взгляд.
- `bipych-mango-cobalt.png` — манговый с синим, широкий низкий корпус.
- `bipych-cream-red.png` — сливочный с красным, более плоский верх.
- `bipych-turquoise-pink.png` — бирюзовый с розовым, слегка асимметричная форма.
- `bipych-cobalt-lemon.png` — кобальтовый с лимонными глазами, лапками и спутником.
- `bipych-sage-terracotta.png` — светлый шалфей с терракотой, вытянутый силуэт и крупные ноги.

На каждом листе показаны обычное состояние, любопытство и радость. Изображения созданы встроенным image_gen с опорой на `../../tech/bit-light.png`; полные промпты сохранены в `prompts.json`. Это иллюстрации для выбора направления, а не подготовленные к интеграции спрайты. Код и контракты приложения не изменены.
