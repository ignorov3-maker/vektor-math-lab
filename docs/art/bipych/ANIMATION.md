# Анимации Бипыча

Реализован этап CX-2 и SVG-слои косметики из CX-6. Выбранные малиновая, бирюзовая и чёрная версии перенесены в программный SVG. Внешность изменена по прямому указанию владельца: вместо робота Дробика используется пиксельный Бипыч; круг на животе отсутствует, цель дня показана отдельной полоской под персонажем.

## Подключение

Подключить styles/drobik.css и content/drobik.js. Сборка, шрифты, CDN и дополнительные зависимости приложению не нужны.

Имя window.VEKTOR_DROBIK и сигнатуры из ТЗ сохранены для совместимости с интеграцией. Видимое имя — Бипыч.

Пример:

    const pet = VEKTOR_DROBIK.mount(element, {
      state: 'idle',
      size: 144,
      age: 'junior',
      cosmetics: { screen: 'screen-turquoise' },
      charge: { done: 2, goal: 5 }
    });
    pet.setState('thinking');
    pet.setCharge(3, 5);
    pet.say('Бип! Кажется, мы что-то нашли.');
    pet.setCosmetics({ screen: 'screen-black', hat: 'hat-cap' });
    pet.destroy();

setCosmetics заменяет набор аксессуаров; для сохранения предметов передавать полную карту. Неизвестные идентификаторы и предметы в неверном слоте игнорируются. Три цвета: screen-raspberry, screen-turquoise, screen-black. Исторический слот antenna используется для пикселя-спутника, а не для антенны робота. У чёрной версии по умолчанию нет спутника; явный аксессуар его добавляет.

Все девять состояний: idle, happy, thinking, confused, proud, shy, catching, celebrate, sleep. Полная цель дня включает короткий танец и возвращает предыдущее состояние. Явный setState отменяет этот переход. Возраст senior снижает интенсивность движения. Настройка prefers-reduced-motion отключает все анимации, сохраняя выражения глаз, позы и аксессуары.

Заряд принимает goal от 3 до 10; done ограничивается диапазоном 0…goal. Статус sleep сам не меняет прогресс ученика: нужный заряд передаёт приложение. Реплика вставляется как текст. Голос включается только при явном say(text, {voice:true}); при отсутствии речи остаётся пузырь.

## Примерочная

Доступны 30 предметов: 3 цвета, 7 пикселей, 10 головных уборов, 10 сачков. Каталог содержит price и unlock. Учёт звёзд, владения и достижений остаётся у приложения. Идентификаторы достижений в каталоге: bug-master, topic-master, ten-bugs; при интеграции их нужно сопоставить с событиями учебного ядра.

## Проверка

Интерактивная демостраница: assets/drobik/demo.html. Она показывает три цвета, девять состояний, примерочную, размер от 32 px, реплики, заряд и четыре оформления существующего продукта.

Браузерный тест: python tests/codex_visual.py. Использует уже применяемый в проекте Python Playwright. Для локального Chrome можно указать CODEX_BROWSER_EXECUTABLE; для снимков — CODEX_SCREENSHOT_DIR. Для запуска в CI интегратор добавляет эту команду после существующего e2e: общий workflow не изменён согласно владению файлами в ТЗ.

Проверены публичный контракт, 26136 сочетаний аксессуаров и состояний, защита текста реплики, неизвестные параметры, очистка при destroy, отсутствие внешних запросов, reduced motion, четыре оформления при 1440 и 390 px. Юнит-тесты генераторов, наставника, геймификации и worker прошли; существующие сценарии ученика и учителя — 62 из 62.

Размер программного SVG без аксессуаров — около 4 КБ; общий модуль с CSS — около 21 КБ. Растровые концепты из docs/art не загружаются демостраницей и не входят в графику продукта.
