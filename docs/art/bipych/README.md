# Бипыч

Рабочее смешное имя для выбранного пиксельного спутника «Вектора». Читается «Би́пыч»: от компьютерного «бип» и дружеского обращения к напарнику. Имя предложено владельцу, но пока не утверждено.

По запросу владельца подготовлены четыре сочетания цветов с небольшими различиями пропорций и взгляда. У всех сохранены ступенчатый контур, короткие руки и ноги, два глаза и отделившийся пиксель-спутник.

- `bipych-peach-teal.png` — персиковый корпус, тёмная бирюза, яркие бирюзовые детали, оранжевый спутник. Более приземистый, один глаз чуть выше другого.
- `bipych-lemon-violet.png` — лимонный корпус, фиолетовая окантовка, сиреневые детали, оранжевые акценты. Чуть более вытянутый.
- `bipych-sky-coral.png` — небесно-голубой корпус, синий контур, коралловые акценты и спутник. Компактные пропорции, внимательный взгляд.
- `bipych-raspberry-cream.png` — насыщенный малиновый корпус, сливовые контур и глаза, сливочные лапки, жёлтые детали. Самая яркая палитра.

Каждый лист показывает обычное состояние, любопытство и радость. Иллюстрации являются концептами для выбора, не готовыми спрайтами. Единая пиксельная сетка, точные цвета, прозрачные фоны и анимационные состояния потребуют отдельной подготовки для продукта. Программные файлы не менялись.

Изображения созданы встроенным image_gen с опорой на `../tech/bit-light.png`. Полные промпты сохранены в `prompts.json`.
