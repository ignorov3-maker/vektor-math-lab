# Жест смущения

В состоянии shy Бипыч опускает взгляд, краснеет и дважды нерешительно касается указательными пальчиками перед собой. Контакт, разведение лапок и повторный контакт образуют цикл 3,2 секунды; у senior — 4 секунды. Отдельная пара пиксельных лапок заменяет боковые, поэтому лишних рук нет.

Купленный сачок в этой позе поставлен рядом; при выходе из shy возвращается в лапку. Владение и экипировка не меняются. Без анимации сохраняется статичная поза с близко сведёнными пальчиками.

Контрольный лист показывает три фазы на трёх цветах и вариант с сачком. Тест проверяет два реальных соприкосновения кончиков, промежуток между ними, скрытие прежних лапок, румянец и сохранение аксессуара. Общий набор — 203 проверки.
