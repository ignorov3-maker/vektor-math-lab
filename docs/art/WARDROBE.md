# Покупки в гардеробной

Гардеробная доступна прямо в assets/drobik/demo.html#wardrobe-section и в демо коллекции. Каталог разделён на «Магазин» и «Мои вещи», внутри — четыре категории. Купленную вещь можно надеть; снятие аксессуаров сохраняет покупки. После покупки категория не сбрасывается.

Для интерактивных демо добавлен отдельный assets/drobik/wardrobe.js с window.VEKTOR_WARDROBE. Он хранит пробный баланс, owned и equipped под ключом vektor-bipych-wardrobe-v1. Первоначально доступны 90 пробных звёзд, три выбранных цвета и первый сачок. Пополнить пробный баланс можно отдельной кнопкой. Реальные учебные звёзды, сервер и данные учеников не используются.

API демохранилища: getState(), buy(id), equip(slot,id), clearAccessories(), addDemoStars(amount), subscribe(fn). Изменения возвращают Promise. Покупка проверяет цену, владение и признак награды. Повторная покупка уже принадлежащей вещи не списывает звёзды. При недоступном хранилище операция завершается ошибкой без изменения сохранённого баланса. В браузерах с Web Locks покупки из разных вкладок сериализуются, storage-события обновляют вторую вкладку.

Сам VEKTOR_COLLECTION по-прежнему принимает данные и обработчики по прежнему контракту. Демо подключает к ним локальное хранилище. Свободная примерка вынесена в раскрываемый блок; она не выдаёт вещи и не сохраняет неприобретённые аксессуары.

Сачок исправлен отдельно: симметричные обод и сетка, общий центр ручки и лапки, единая группа движения. Предмет больше не поворачивается независимо от руки.

Проверки: tests/codex_wardrobe.py — 31 из 31, включая перезагрузку, две вкладки, двойную покупку, недостаток средств, награды, отказ сохранения и четыре оформления на 1440/390 px. В общий тест добавлена проверка геометрии сачка. Полный визуальный набор — 196 из 196.
