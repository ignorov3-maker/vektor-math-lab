# Подключение визуальных модулей Вектора

Собранная ветка: codex/vektor-ui. Главная страница предпросмотра: assets/showcase/index.html. Все изменения лежат в разрешённых ТЗ файлах; main, учебная логика, основные экраны, сервер и общий workflow не изменены. PR не создан: владелец разрешил отправку в свои ветки, а автоматическая проверка отдельно остановила создание PR.

## Готовые модули

- CX-1 — история концептов и выбранные три цвета в docs/art/bipych/selected.
- CX-2 — content/drobik.js, styles/drobik.css, assets/drobik/demo.html. Девять состояний, три цвета, junior/senior, реплики, голос при наличии системного голоса, заряд 3…10, уменьшение движения.
- CX-3 и CX-4 — content/art.js, assets/bugs/demo.html. 21 ключ жучка, 20 уникальных рисунков, три статуса, 12 интересов.
- CX-5 и CX-6 — content/collection.js, assets/collection/collection.css, assets/collection/demo.html. Коллекция, звания, пустое состояние, фильтры, 30 предметов косметики, примерочная и обработчики покупки/экипировки. Покупки доступны также в демо персонажа; пробный баланс и вещи сохраняются в браузере через отдельный assets/drobik/wardrobe.js.
- CX-7 — board.html, assets/board. Слайды из vektor-board, стрелки, клик, ответы, безопасный HTML и формат проектора.
- CX-8 — landing/index.html и landing/pitch.html. Лендинг и семь сцен питча, метрики «Скоро».
- CX-9 — print/stickers.html и print/slip.html. 24 наклейки и восемь шаблонов входа на A4.
- CX-10 — tests/codex_visual.py и шесть дополнительных наборов. Команда python tests/codex_visual.py проверяет все доступные визуальные модули в собранной ветке.

## Важные решения

Последние указания владельца меняют внешний образ из исходного ТЗ: пиксельный Бипыч заменяет робота; антенны и круглого индикатора на животе нет. Цель дня показывается отдельной полоской. Совместимый идентификатор VEKTOR_DROBIK оставлен. Слот antenna используется для пикселя-спутника. У чёрного персонажа по умолчанию нет спутника, как на выбранном исходнике.

Контракты функций не менялись. Модули не записывают учебный прогресс и не управляют реальными звёздами. Данные и обработчики передаёт приложение. Примеры используют отдельные подготовленные записи и пробные звёзды.

## Порядок подключения интегратором

1. Подключить styles/drobik.css и content/drobik.js в основных экранах. На главной передавать реальную цель дня; в тренировке менять state по событиям и освобождать экземпляр через destroy при замене экрана.
2. Подключить content/art.js для иллюстраций жучков и интересов.
3. Подключить assets/collection/collection.css и content/collection.js. Передать bugs/rank или stars/owned/equipped с обработчиками. После покупки и экипировки повторно передавать актуальные данные.
4. Сопоставить каталожные unlock bug-master, topic-master и ten-bugs с достижениями учебного ядра.
5. Перед открытием board.html записывать данные мини-урока в localStorage['vektor-board'] на том же HTTP-источнике.
6. Добавить в общий workflow установку тестовой зависимости pypdf и команду python tests/codex_visual.py после текущего e2e. Playwright уже есть в существующем workflow.

## Проверка

Для браузерных проверок нужны Python Playwright и Chromium; для печатных — pypdf. Это тестовые зависимости, в продукт они не входят. На машине с установленным Chrome можно указать CODEX_BROWSER_EXECUTABLE.

Команды:

    python tests/codex_visual.py
    python tests/e2e_scenarios.py
    node tests/generators.test.js
    node tests/tutor.test.js
    node tests/game.test.js
    node tests/worker.test.mjs

Отдельно проверены: анимации и геометрия сачка 46/46, рисунки 15/15, коллекция 54/54, покупки и сохранение гардеробной 31/31, доска 12/12, лендинг и питч 28/28, печать 10/10. Всего 196 проверок, общий запуск зелёный. Существующий e2e — 62/62; 27000 сгенерированных задач без ошибок, остальные модульные проверки зелёные.

Восемь вариантов оформления демо анимаций проверены при 1440/390 px. Коллекция — также при 768 px. Каждый SVG состояния около 4 КБ; модуль персонажа с CSS и модуль рисунков вместе около 33 КБ, ниже лимита 400 КБ. Растровые концепты и снимки лежат только в docs/art и не загружаются продуктом.
