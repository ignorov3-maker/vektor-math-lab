# Режим доски

Реализован CX-7. board.html читает localStorage['vektor-board'] по контракту ТЗ: kidName, title, slides с kind, html, question и answerHtml. Принимаются первые три корректных слайда; математическое содержание страница не вычисляет.

Стрелки, кнопки и клик по содержимому меняют слайд. Пробел и «Показать ответ» открывают пояснение. При показе ответа вопрос временно заменяется ответом, чтобы сохранить место на проекторе. При смене слайда ответ снова скрыт. Есть полноэкранный режим.

Бипыч показывает растерянность, размышление и гордость в зависимости от слайда. В HTML сохраняются дроби и базовая SVG-графика движка; сценарии, обработчики событий, внешние ресурсы и активные элементы удаляются перед вставкой.

Пример с заранее подготовленными данными: assets/board/demo.html. Для перехода из примера используется общее локальное хранилище одного HTTP-источника.

Проверка python tests/codex_board.py — 12 из 12. Проверены данные учителя, пустое и повреждённое хранилище, ответы, клавиатура, безопасный HTML, размер шрифта от 40 px на 1280×720, размещение примера на экране и отсутствие горизонтальной прокрутки на 390 px. Основной кабинет учителя не изменён.
