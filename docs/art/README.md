# Штрих

Новый концепт маскота «Вектора», 27 октября 2026 года.

По прямому указанию владельца прежний образ Дробика пересмотрен: убраны робот, антенна, дроби и круглый индикатор на животе. Название нового персонажа — Штрих.

Штрих — вымышленный лесной зверёк с характером наблюдателя. Он любопытный, уверенный, немного ироничный. Помогает заметить странность в решении и радуется находке вместе с учеником.

Опознавательные черты: изумрудный силуэт, уши разной формы, жёлтый штрих на загнутом ухе, светлая мордочка, широкий хвост как росчерк. На листе показаны спокойная поза, поиск и сдержанная радость.

Изображение: `shtrikh-concept.png`. Это концепт для выбора художественного направления; готового SVG-модуля и анимаций пока нет. Для маленьких размеров потребуется упростить контур и детали лап. Нынешняя генерация содержит мягкую светотень: при переводе в SVG использовать сплошные заливки.

Создано встроенным инструментом image_gen. Полный промпт сохранён в `shtrikh-prompt.txt`. Исходные концепты `drobik-concept-a.png`, `drobik-concept-b.png`, `drobik-concept-c.png` отклонены владельцем и оставлены только как история поиска.

Новый образ ещё не утверждён. Программные контракты, учебная логика и файлы приложения не изменены.
