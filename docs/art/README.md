# Бипыч и визуальные модули Вектора

Текущий персонаж выбран владельцем: пиксельный напарник в малиновой, бирюзовой и чёрной версиях. Рабочее имя — Бипыч. Прежние роботы Дробик и зверёк Штрих отклонены; их изображения сохранены только как история поиска.

Общий интерактивный предпросмотр: assets/showcase/index.html. Полный состав, проверка и порядок подключения описаны в HANDOFF.md в этой папке.

Программные глобальные имена из контракта сохранены, включая VEKTOR_DROBIK. Видимое имя и внешность соответствуют последним указаниям владельца.
