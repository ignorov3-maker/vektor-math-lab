# Лендинг и питч

Реализован CX-8: landing/index.html и landing/pitch.html, локальные CSS и JavaScript без сборки, CDN, аналитики и внешних шрифтов.

Лендинг описывает рентген мышления, четыре этапа, пользу учителю и родителям; ведёт к демо персонажа, коллекции, каталогу и примеру доски. Разработка явно обозначена как подготовка к пилоту. Все три метрики пилота показаны как «Скоро», отзывы и достижения не выдуманы.

Контакт — новая тема в Issues фактического репозитория проекта. Доступность Issues проверена через GitHub. Кнопка лишь открывает страницу по действию посетителя; автоматической отправки сообщений или сбора данных нет.

Питч содержит семь сцен по временному сценарию раздела 10.1 ТЗ: исходная ошибка, цикл разбора, действие учителя, объяснение напарнику, пробел из 5 класса у старшего ученика, метрики и приглашение школ к пилоту. Пример с шестью учениками обозначен как демонстрационный. Карта 5–9 классов обозначена как следующий этап. Есть стрелки, клавиатура и полноэкранный режим.

Проверка python tests/codex_landing.py — 28 из 28. Проверены размеры 1440, 768 и 390 px, контрпример, отсутствие внешних ресурсов и ошибок, семь сцен на 1280×720, навигация и заглушки метрик.
