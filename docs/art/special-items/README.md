# Особенные вещи и сон Бипыча

Восемь предметов дополняют прежний каталог: комета, НЛО, шляпа мага,
мухомор, аркадный шлем, орбитальный сачок, сачок-соты и ловец комет.
Формы нарисованы ступенями, без кривых, градиентов и растровых текстур.
У семи вещей есть небольшие эффекты; сачок-соты отличается сеткой и рамкой.
Сачок «Соты охотника» переработан: семь полых ступенчатых ячеек,
тонкая сетка без заливки, золотистая рамка с тёплым контуром и бликами.

Шляпа мага — награда topic-master, ловец комет — ten-bugs. Остальные
доступны за пробные звёзды в демо. Реальную выдачу наград выполняет ядро
приложения через существующие owned/equipped и обработчики.
Дополнительное поле description в каталоге необязательно; оно позволяет
показать вещь во вкладке «Особенные». Публичные методы сохранены.

Во сне три Z с разными фазами поднимаются, увеличиваются и исчезают.
Они находятся вне качающегося тела; эффекты аксессуаров во сне замирают.
Настройка уменьшения движения отключает все анимации, сохраняя видимые Z.

Проверены 52920 сочетаний, примерка наград без покупки, покупка нового
спутника с сохранением после перезагрузки, четыре оформления и мобильная
ширина. Общий набор — 219 проверок. special-items.png показывает новые
вещи, sleep-frames.png — кадры сна на трёх цветах.
