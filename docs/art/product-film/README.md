# Демонстрационный ролик Вектора

Обновлённая версия с реальными учебными экранами Vercel:
vektor-product-live.mp4. Монтаж и происхождение кадров описаны в LIVE-SOURCE.md;
просмотр с перемоткой — assets/film/live.html. Первый вариант ниже сохранён.

Первый согласованный вариант: горизонтальный MP4, 36 секунд, 1920×1080,
30 кадров/с, без звука. Бипыч, гардеробная и коллекция используют настоящие
модули проекта. Мини-урок загружается из board.html с подготовленными данными.
Ролик показывает прототип визуальной части, а не интеграцию учебного ядра.

## Сцены

| Время | Что показано |
| --- | --- |
| 0–4 с | Три цвета Бипыча, знакомство с проектом |
| 4–10 с | Думает, смущается, гордится |
| 10–20 с | Примерка цвета и кепки, покупка 90 → 55 звёзд, экипировка, особенные вещи |
| 20–26 с | Коллекция, фильтр побед, история победы |
| 26–32 с | Три шага мини-урока и показ верного ответа |
| 32–36 с | Финал с персонажами в аксессуарах |

## Файлы и правки

- vektor-demo.mp4 — готовый ролик.
- poster.png — обложка.
- storyboard.png — контактный лист сцен.
- assets/film/index.html, film.css, film.js — редактируемая версия с просмотром и перемоткой.
- assets/film/render.py — покадровый экспорт в MP4 через Chrome и FFmpeg.

Тайминг и действия задаются в film.js. Подписи находятся в index.html,
композиция — в film.css. Кошелёк ролика находится в памяти страницы;
подготовленные данные урока подаются только внутри его iframe.
Сохранённые покупки и мини-уроки пользователя не меняются.

Для экспорта нужны Python Playwright, Pillow, Chrome/Chromium и FFmpeg с
libx264. Это инструменты экспорта, в продукт они не включаются.
CODEX_BROWSER_EXECUTABLE указывает браузер, FFMPEG_EXECUTABLE — FFmpeg:

    python assets/film/render.py --output output/product-film

Проверка сцен без сборки видео:

    python assets/film/render.py --qa --output output/product-film-check

Проверены покупка и надевание кепки, совместная примерка НЛО и сачка,
переход к третьему слайду урока и раскрытие ответа, отсутствие ошибок JS.
MP4 проверен декодированием всех кадров и воспроизведением в Chrome:
36 секунд, 1080 кадров, H.264, 1920×1080, 30 fps, без аудиодорожки.
Размер первого ролика — 4 509 142 байта. У браузерной версии проверены
воспроизведение, пауза, перемотка и ширина 390 px. Сохранённые данные
кошелька и урока после просмотра остаются неизменными.
