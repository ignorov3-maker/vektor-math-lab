# Бит

Текущее направление маскота «Вектора», 27 октября 2026 года.

Владелец выбрал первого из трёх технологичных спутников — пиксельного персонажа (`bit-original.png`) — и попросил сделать его светлее и немного необычнее. Текущая доработка: `bit-light.png`.

Рабочее имя — Бит. Светлый кремово-мятный корпус, изумрудный контур и глаза, жёлтые акценты. Главная отличительная черта — отдельный золотистый пиксель, парящий возле выемки в верхнем углу. В анимациях он может возвращаться в выемку, указывать на важную деталь или подпрыгивать вместе с персонажем.

Лист показывает спокойное состояние, любопытство и радость. Это концепт, а не готовый игровой спрайт или анимационный модуль. Перед использованием в продукте нужен чистый SVG или согласованный спрайт с единым размером пикселя. Положение спутника пока иллюстративное; анимация не реализована.

Остальные варианты сохранены для истории: `node-concept.png` — гладкий модуль; `glide-concept.png` — парящий спутник. Предыдущие образы робота Дробика и зверька Штриха отклонены владельцем.

Все изображения созданы встроенным image_gen. Полные промпты и файл-источник для доработки указаны в `prompts.json`. Код приложения и программные контракты не изменены.
