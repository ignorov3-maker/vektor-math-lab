# Печатные материалы

Реализован CX-9: print/stickers.html — 24 наклейки «Жучок побеждён» на одном A4; print/slip.html — восемь карточек входа на одном A4. Поля шаблона сохранены буквально: {login}, {password}, {class}, {url}. Настройки печати: A4, 100%, без колонтитулов. Поля 10 мм, контуры помогают разрезать лист.

Для заполнения карточек в окне шаблона доступен VEKTOR_PRINT.fill(rows), где rows — массив до восьми объектов с login, password, class, url. Значения вставляются как текст. Несколько листов готовит интегратор отдельными пакетами. Реальные данные учеников в демо не используются.

Персонажи и жучки печатаются как SVG; анимации в режиме печати отключены. PNG-концепты не загружаются.

Проверка python tests/codex_print.py использует Playwright и pypdf только для тестов. Результат: 10 из 10. Chrome напечатал каждый шаблон ровно на одной странице A4; проверены 24/8 карточек, размеры страницы, четыре метки и безопасное заполнение. Контрольные PDF отрендерены Poppler, обе страницы визуально проверены.
