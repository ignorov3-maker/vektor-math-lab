# Демо «Вектора» на сцене (3 минуты)

Всё работает на Vercel + Supabase. ИИ в сценарии не нужен — если ИИ или Wi‑Fi в зале подведут, демо всё равно пройдёт.

## Один раз
1. Supabase → SQL Editor: по очереди выполнить `supabase/schema.sql`, `test.sql`, `admin.sql`, `teacher.sql`, `pulse.sql`, `pilot_report.sql`, затем `tools/demo/seed.sql`.
2. Там же: `select vk_demo_seed('ваш-пароль');` — создаст класс «Демо» (25 учеников-ботов с именами), ученика ведущего `демо` и учителя `демо-учитель`. Пароль у всех один.

## Перед каждой репетицией и перед сценой
1. `select vk_demo_seed('ваш-пароль');` — сбрасывает всё в исходное состояние.
2. На ноутбуке: `DEMO_PASSWORD=ваш-пароль node tools/demo/bots.mjs --minutes 20` — живой класс. Шестеро ботов сразу «складывают знаменатели», трое «прилипалы», двое «хвастуны знаменателем»; на задачу учителя отвечают через 5–15 секунд.
3. Телефон: сайт → вход `демо`. Ноутбук: `teacher.html` → вход `демо-учитель`.

## Сценарий (раздел 10.1 ТЗ)
| Время | Где | Что делаем |
| --- | --- | --- |
| 0:20 | телефон | Тема «Разные знаменатели» → в задаче 1/2 + 1/3 ввести 2/5 → «Поймать жучка» → «Готово» → «Разобраться» → «Нет» на контрпримере → решить заново → двойник ✓ |
| 1:00 | ноутбук | Пульс: «Складывает числители и знаменатели · 6 учеников» → «Мини-урок на доску» → «Дать задачу этим 6» → через 5–15 с появляются ✓ |
| 2:30 | ноутбук | «Сводка урока» — рекомендация на следующий урок |

Пока не готово (по плану после): «Научи Дробика» (решили не делать) и «дыра из 5 класса» у девятиклассника.

## Метрики пилота
`select jsonb_pretty(vk_pilot_report());` — снятые жучки, доля решающих по шагам, время реакции учителя, вовлечённость.

## Проверка, что демо не сломается
`python tests/demo_scenario.py` — прогоняет весь сценарий на локальной базе с ботами (нужны Postgres и Playwright). Зелёный — можно выходить на сцену.
