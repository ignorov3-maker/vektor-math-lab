# Темы «Вектора» 5–9 класса: формат и требования

Источник содержания — **Федеральная рабочая программа «Математика. 5–9 классы (базовый уровень)»** (ФОП ООО, приказ Минпросвещения № 370). Курсы: «Математика» 5–6 (разделы: Натуральные числа, Дроби, Положительные и отрицательные числа, Буквенные выражения, Текстовые задачи, Наглядная геометрия), «Алгебра» 7–9, «Геометрия» 7–9, «Вероятность и статистика» 7–9. Сверка с программой — документ «Вектор × ФРП» (раздел 5–9 по классам).

## Идея продукта — что должна делать каждая тема

«Вектор» находит не ошибку, а **неверное правило в голове** ребёнка и чинит его:

1. **Находит** — по неверному ответу понимает, какое правило сработало (`wrongs`).
2. **Сталкивает** — простой конкретный пример, где это правило даёт абсурд (`conflicts`).
3. **Чинит** — одна верная идея (`fixIdea`) и та же задача заново.
4. **Проверяет через дни** — ловушки: задачи, где это правило даёт правдоподобный неверный ответ (строит kit из `generate` + `wrongs`).
5. **Учителю** — Пульс класса и мини-урок на доску (строит kit).
6. **«Дыра из 5 класса»** — `root` у ошибки показывает тему младшего класса, где эта ошибка родилась.

Объяснения — **конкретные и живые**: ребёнок видит настоящую ситуацию (магазин, дорога, рецепт, спорт, игра), а не абстракцию. Сначала пример, потом правило.

### Ошибка (жучок мысли)

Только **реальные типичные ошибки**, известные в методике (не выдуманные). Каждая — это неверное правило, которое даёт **конкретный предсказуемый неверный ответ**.

```js
{
  id: 'move-without-sign',
  title: 'Переносит слагаемое, не меняя знак',             // методическое название (для 8–9 класса и учителя)
  kidName: 'Беззнаковик',                                   // имя жучка для 5–7 класса, одно-два слова, не обидное
  kidRule: 'ты переносишь число через «=», а знак оставляешь прежним', // начинается с «ты …»
  say: 'Подсказка после неверного ответа: в чём ошибка, 1–2 предложения, без ответа задачи.',
  fixIdea: 'Одна верная идея, которая чинит правило.',
  explainOptions: ['верное объяснение', 'правдоподобное неверное', 'ещё одно неверное'], // ровно 3, верное ПЕРВЫМ
  conflicts: [  // 1–2 контрпримера: простой случай, где правило даёт абсурд. Числа проверь сам.
    { text: 'x + 2 = 5. По твоему правилу x = 5 + 2 = 7. Подставь: 7 + 2 = 9, а не 5.', ask: 'Подходит x = 7?', choices: ['Да', 'Нет'], right: 'Нет',
      verify: () => 7 + 2 !== 5, figure: {...}? },
  ],
  root: 'z6-addsub',  // необязательно: тема младшего класса, где родилась ошибка («дыра из 6 класса»)
}
```

### Задача — что возвращает generate(lv)

```js
{
  story: 'Короткая живая ситуация (может быть пустой для «чистого» примера).',
  question: 'Что найти? (с единицами, если есть: «Ответ в км»)',
  figure: { type: … }?,
  answer: ans(x),                 // строка: '12', '-3', '2.5', '3/4' — ИЛИ строка из choices
  accept: 'exact',                // 'exact' (число), 'equivalent' (дробь, можно несократимую), 'simplest' (дробь, надо сократить), 'choice'
  choices: ['острый', 'тупой', 'прямой']?, // только для accept: 'choice', 2–4 варианта, answer — один из них
  hints: ['наводящая подсказка', 'почти решение'],   // ≥ 2, без готового ответа в первой
  solution: 'Решение по шагам с ответом.',
  wrongs: { 'move-without-sign': ans(7), 'other-id': ans(…) }, // ответ, который дало бы каждое неверное правило на ЭТОЙ задаче
  data: { a, b, c },              // параметры для verify (JSON)
}
```

- **Ответ — одно число или вариант.** Если в задаче несколько ответов — спроси один: «больший корень», «x», «сумму координат», «сколько корней». Десятичные — до 2 знаков. Корни/π — спроси так, чтобы ответ был числом: «найди S/π», «найди x², если x = √…», «впиши значение под корнем».
- **wrongs** — главное для «Рентгена». Для каждой ошибки темы посчитай, какой ответ она даёт на этой задаче. Если неверное правило к задаче не применимо или случайно даёт верный ответ — просто не пиши его ключ. Каждая ошибка должна встречаться в `wrongs` хотя бы на части задач уровня 2.
- Неверные ответы тоже должны быть правдоподобными: ловушку kit выбирает из задач, где неверное правило даёт целое или число с 1–2 знаками. Подбирай параметры так, чтобы так было на большинстве задач.
- **Числа «удобные»**: подбирай параметры так, чтобы ответ был целым или с 1–2 знаками, без деления «в столбик на 7». Уровни: 1 — однозначные/простые, 2 — обычные из учебника, 3 — двухшаговые или с подвохом.
- **Разнообразие**: ≥ 3 сюжета на тему (магазин, спорт, путешествие, кухня, игры, школа), разные формулировки, разные типы вопроса внутри темы.
- В тексте: `num()` для чисел (запятая, «−»), `fr(a,b)` для дробей, `x<sup>2</sup>` для степеней, `√` для корня. Никогда не пиши в текст `ans()` и `1.5` с точкой.
- Тексты на «ты», дружелюбно, коротко. Без «Вычислите» — «Найди», «Сколько», «Чему равно».

### verify(task)

Пересчитай ответ **другим путём**, из `task.data` — подстановкой корня, перебором, формулой в другом виде. Верни `true`, если `task.answer` верен. Тест прогоняет 1500 задач.
