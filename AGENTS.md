# AGENTS.md — правила для Codex

«Вектор» — веб-платформа по математике для 5–9 класса. Ядро — «Рентген мышления»: находим неверное правило в голове ребёнка («жучок мысли») и помогаем его победить. Маскот — пиксельный Бипыч (идентификатор в коде — `VEKTOR_DROBIK`, исторически).

## Стек
Статический сайт без сборки: `index.html`, `app.js`, `content/*.js`, `style.css`, `skins.css`. Чистый JavaScript без фреймворков; модули отдают себя через `window.VEKTOR_*`. Хостинг — Vercel (выкладка из `main`, предпросмотр для PR), данные — Supabase. Цвета бренда — переменные в `:root` файла `style.css` (`--green`, `--ink`, `--paper`, `--marker`, `--margin`). Четыре скина: тетрадь, орбита, стикеры, пиксель — графика должна выглядеть прилично во всех.

## Образ маскота
Решение владельца: пиксельный Бипыч заменил робота из исходного ТЗ (подробности — `docs/art/HANDOFF.md`). Ниже — исходный образ, сохранён для истории.

Небольшой округлый робот. Голова — экран, эмоции — глаза на экране. Антенна в форме «/» (знак дроби). На животе круглый индикатор заряда, разделённый на доли, как пицца: закрашенные доли = решённые задачи цели дня. Цвета: зелёный `#1E7358`, белый, жёлтый `#FFE58A` (заряд), коралловый `#E46A5E` (жучки). Характер: любопытный, смелый, сам иногда ошибается, на «ты», никогда не ругает. Дизайн оригинальный, не похожий на известных персонажей.

Жучки — маленькие милые (не страшные) персонажи, у каждого черта, напоминающая ошибку. Список ключей — в `docs/contracts.md`.

## Правила
1. Одна задача — одна ветка `codex/<задача>` от свежего `main` — один PR в `main`. Свои PR не сливать: сливает владелец.
2. Менять **только** свои файлы: `assets/**`, `content/drobik.js`, `content/art.js`, `content/collection.js`, `styles/drobik.css`, `board.html`, `landing/**`, `print/**`, `docs/art/**`, `tests/codex_*.py`.
   Общие файлы (`index.html`, `app.js`, `style.css`, `teacher.html`, остальные `content/*`, `supabase/*`) не трогать — подключение делает Claude.
3. Никаких внешних ресурсов: Google Fonts, CDN, аналитики, npm-зависимостей, шага сборки.
4. Графика оригинальная, без чужих брендов и персонажей. Сгенерированные картинки — только концепты в `docs/art/`; в продукт идёт чистый SVG.
5. Анимации — CSS, отключаются при `prefers-reduced-motion`. Вся графика маскота и жучков — до 400 КБ, до 15 КБ на состояние маскота.
6. Не делать логику учёбы, проверки ответов и сервера — это зона Claude.
7. Не придумывать цифры и отзывы для лендинга и слайдов (заглушка «скоро»).
8. Контракт (`docs/contracts.md`) меняется только отдельным PR.
