# vektor-math-lab
Интерактивный учебный прототип по математике (5–6 классы) — статическая версия для GitHub Pages.

Открой `index.html` в браузере — сборка не нужна. Прогресс хранится в `localStorage` этого браузера.

## Что внутри
- **Маршрут** по разделу «Обыкновенные дроби» (9 тем по федеральной рабочей программе 2025).
- **Методичка каждой темы**: цель, наглядная модель, правило, разобранные примеры, частые ошибки.
- **Занятие в три этапа**: разбор → тренировка (задачи генерируются, подсказки по одной) → проверка из 4 задач (засчитывается от 3 верных).
- **Распознавание типичных ошибок** по ответу (например, «сложил знаменатели») — с объяснением ученику и счётчиком для учителя.
- **Повторение** освоенной темы через 1, 3 и 7 дней.
- Диагностика, карта знаний, отчёт для преподавателя, четыре стиля оформления.

## Структура
- `content/fractions.js` — методички и генераторы задач раздела «Обыкновенные дроби».
- `content/check.js` — разбор и проверка ответов (дроби, смешанные числа, знаки сравнения).
- `app.js` — экраны и логика прогресса; `style.css`, `skins.css` — оформление.
- `tests/generators.test.js` — автотест: `node tests/generators.test.js` (27 000 сгенерированных задач).

## Как добавить тему
Добавьте объект в массив `topics` в `content/fractions.js` (или новый файл раздела) с полями
`id, title, goal, requires, explain, mistakes, generate()` и запустите тест.
