# vektor-math-lab
Интерактивный учебный прототип по математике (5–6 классы) — статическая версия для GitHub Pages.

Открой `index.html` в браузере — сборка не нужна. Прогресс хранится в `localStorage` этого браузера.

Разделы: маршрут по теме «Дроби», карта знаний с фильтрами, занятия с задачей и пошаговыми подсказками, диагностика из трёх вопросов, сводка для преподавателя, настройки.
